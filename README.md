# stereogram-archive
The Stereograph Archive - a dark gallery of public domain vintage stereograph photographs

Catalog schema: **v2** — the catalog of record is the per-item records in `records/` (machine-readable schema in [schema/catalog-v2.schema.json](schema/catalog-v2.schema.json), fields documented in [docs/DATA_DICTIONARY.md](docs/DATA_DICTIONARY.md), enforced by `tools/validate_catalog.py --v2`). `data.json`, `catalog-v2.json`, `browse.json`, `vr.json`, and `search/` are generated by `tools/build_catalog.py` from the records; do not edit them by hand. The v1 schema ([schema/catalog.schema.json](schema/catalog.schema.json)) describes the generated `data.json` item shape the pages consume.
