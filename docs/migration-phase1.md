## Field coverage after migration

- creator: 288 of 515 records (creator_dates present on 92). Extracted mechanically from the title's own "by …" attribution; the name is kept exactly as printed, with life dates split into creator_dates when the attribution prints them.
- date_edtf: 390 of 515; 125 honestly null (104 records were already "Undated" in v1; 21 more became Undated in WS3 below — a life-date artifact is not a date for the photograph).
- rights_uri: 501 of 515. The 14 "No restrictions" records carry no URI: their Commons license evidence is the Flickr Commons "no known copyright restrictions" usage page, which is not a RightsStatements or Creative Commons identifier, so rights_uri is null and rights_basis records the source's own statement.
- Source pinning: page ID 515/515, revision ID 515/515, SHA-1 515/515. Revision gaps for the sweep's 326 items were filled from the Commons API by page ID (the latest revision of each file page). All 515 SHA-1 values and license labels were cross-checked against the API: 0 mismatches on each.
- publisher_series: stated affirmatively for exactly 1 record (STA-0242, "Sterographs of the Black Hills", the source's own spelling, from its description). All other records: null — the field stays honestly sparse.
